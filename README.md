# Smart Automatic Attendance System Using ESP-12E and Android Application

## Project Overview

The Smart Automatic Attendance System is an Android-based attendance solution that uses an ESP-12E (ESP8266) as a classroom Wi-Fi beacon. The system automatically records student attendance when an active attendance session is started by the teacher and the student's Android application detects the classroom Wi-Fi network.

The project aims to provide a fast, contactless, and automated attendance process while reducing manual effort and improving attendance accuracy.

---

## Technology Stack

* **Android Application:** Java (Android Studio)
* **Backend:** Python (Flask)
* **Database:** MySQL
* **ESP Device:** ESP-12E (ESP8266)
* **Version Control:** Git & GitHub
