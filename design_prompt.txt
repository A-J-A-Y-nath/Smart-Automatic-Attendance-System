# Figma AI Mobile Redesign Prompt: Smart Automatic Attendance System

Use `ui_reference.svg` as the visual and structural source of truth. Create an editable, production-grade Android mobile UI redesign (Material 3 with refined glassmorphism, 390x844 dp frames).

## Design System & Redesign Guidelines
- Role & Screen Authenticity: Preserve all existing screens, user roles (Student, Teacher, Admin), hierarchy, and information architecture exactly as represented in `ui_reference.svg`. Do NOT add new screens, invent hypothetical features, or alter the core functionality.
- Visual Language: Elevate the current UI into a modern, clean, and cohesive enterprise educational product. Use a curated palette based on the existing tokens: Forest Green primary (`#1B8B3E` / Container `#E8F5E9`), Dark Navy headings/toolbar (`#1A2340`), Slate secondary text (`#6B7A99`), Soft background gradient (`#F4F6FA` to `#E8EDF5`), Crisp white glassmorphic cards (`#FFFFFF`, stroke `#E2E8F0`, corner radius 20–24 dp), and distinct status indicators (Green `#1B8B3E` for Present, Red `#E53935` for Absent, Amber `#B45309` on `#FFFBEB` for Proxy alerts).
- Typography & Spacing: Apply an 8dp grid system with balanced padding, clear typographic scale, legible data tables, circular percentage badges, and accessible touch targets (minimum 48dp).
- Components: Create reusable Figma components for Cards, Dropdown Spinners, Text Input Fields, Badges, Buttons (Primary, Outlined, Text), and Modal Dialogs.

## Interactive Figma Prototype Connections

Connect the frames using Figma prototype smart animate transitions according to the actual application navigation logic:

### 1. Authentication & Role-Based Entry
- `Screen 01 (Login)`:
  - RadioButton `Student` + Tap `Login` Button ──(Smart Animate)──► Navigate to `Screen 02 (Student Dashboard - Idle)`
  - RadioButton `Teacher` + Tap `Login` Button ──(Smart Animate)──► Navigate to `Screen 05 (Teacher Dashboard - Idle)`
  - RadioButton `Admin` + Tap `Login` Button ──(Smart Animate)──► Navigate to `Screen 09 (Admin Dashboard - Overview)`

### 2. Student Attendance Flow
- `Screen 02 (Student Dashboard - Idle)`:
  - Tap `Mark Attendance` Button ──(Open Overlay)──► `Screen 03 (Attendance Code Dialog)`
  - Tap `Logout` Button ──(Navigate)──► `Screen 01 (Login Screen)`
- `Screen 03 (Attendance Code Dialog)`:
  - Tap `CANCEL` ──(Close Overlay)──► Returns to `Screen 02 (Student Dashboard - Idle)`
  - Tap `SUBMIT & SCAN` ──(Close Overlay & Navigate)──► `Screen 04 (Attendance Confirmed - Present ✓)`
- `Screen 04 (Attendance Confirmed)`:
  - Tap `Logout` Button ──(Navigate)──► `Screen 01 (Login Screen)`

### 3. Teacher Attendance Session & Live Roster Flow
- `Screen 05 (Teacher Dashboard - Idle)`:
  - Tap `Start Attendance Session` Button ──(Open Overlay)──► `Screen 06 (Beacon Options Picker Dialog)`
  - Tap `Logout` Button ──(Navigate)──► `Screen 01 (Login Screen)`
- `Screen 06 (Beacon Options Picker Dialog)`:
  - Tap `CANCEL` ──(Close Overlay)──► Returns to `Screen 05 (Teacher Dashboard - Idle)`
  - Tap `Classroom Beacon (default)` OR `Teacher Hotspot` OR `Nearby Wi-Fi` ──(Close Overlay & Navigate)──► `Screen 07 (Active Session & Live Roster)`
- `Screen 07 (Active Session & Live Roster)`:
  - Tap `Stop / Cancel Session` Button ──(Navigate)──► `Screen 05 (Teacher Dashboard - Idle)`
  - Tap on `Live Roster List` (or absent student row) ──(Open Overlay)──► `Screen 08 (Manual Override Dialog)`
  - Tap `Logout` Button ──(Navigate)──► `Screen 01 (Login Screen)`
- `Screen 08 (Manual Override Dialog)`:
  - Tap `CANCEL` ──(Close Overlay)──► Returns to `Screen 07 (Active Session)`
  - Tap `Mark` on any absent student ──(Close Overlay)──► Returns to `Screen 07` with updated Present count and student tagged as `[Manual]`

### 4. Admin Management Flow
- `Screen 09 (Admin Dashboard - Overview)`:
  - Tap `+ Add` or `Edit` on Students / Teachers / Classrooms Cards ──(Open Overlay)──► `Screen 10 (Admin Entity Modal)`
  - Tap `Logout` Button ──(Navigate)──► `Screen 01 (Login Screen)`
- `Screen 10 (Admin Entity Modal)`:
  - Tap `CANCEL` ──(Close Overlay)──► Returns to `Screen 09 (Admin Dashboard - Overview)`
  - Tap `SAVE STUDENT` ──(Close Overlay)──► Returns to `Screen 09 (Admin Dashboard - Overview)`
